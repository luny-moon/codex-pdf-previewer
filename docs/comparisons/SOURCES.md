# Image credits

The comparison captures were supplied by the user from a large display. The
original image bytes are preserved. They illustrate those captures; zoom,
display scaling and viewer settings can affect appearance.

- `typography-before.png` and `typography-after.png` show the original
  typography specimen created for this project. The specimen is MIT-licensed.
- `attention-before.png` and `attention-after.png` show an excerpt from
  *Attention Is All You Need*, Vaswani et al. (2017),
  [arXiv:1706.03762](https://arxiv.org/abs/1706.03762). The paper excerpt is
  third-party material and is not covered by this project's MIT license.

In each pair, `before` is the Codex default preview and `after` is the plugin.
Both mappings were confirmed by the user. No complete third-party paper is
included in the repository or plugin package.
