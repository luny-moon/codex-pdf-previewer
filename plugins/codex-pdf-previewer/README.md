# codex-pdf-previewer

Sharper local PDF previews inside Codex.

Give this ZIP or the [GitHub page](https://github.com/luny-moon/codex-pdf-previewer)
to Codex and say **“Install this plugin for me.”**
Then attach a PDF and say **“Open this PDF.”**

Requires Codex desktop and Python 3.10+. Restart Codex if the plugin is not yet visible.
